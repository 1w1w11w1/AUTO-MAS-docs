# 任务管理

## 调度队列

**调度队列** 就是一张待办清单：你把要跑的脚本按顺序放进去，AUTO-MAS 按清单从上到下一个一个跑完。你还可以让它在软件启动时自动开跑，或者到点自动开跑。

::: warning 先搞清楚这两件事
**队列里的脚本是排队跑的**，前一个跑完才轮到下一个。如果你发现几个脚本挤在一起同时跑了，去检查通用脚本设置。

**一个队列可以设多个定时时间，但这些时间不是分配给单个脚本的。** 每到一个时间点，整个队列都会从头跑一遍，而不是"这个点跑脚本 A，那个点跑脚本 B"。
:::

::: info 示例版本与制作说明
本节图文由 **Codex** 制作，界面基于 **AUTO-MAS v5.8.0-beta.3**。示例只演示配置，不执行游戏任务。
:::

### 1. 创建队列并选择启动方式

在 **调度队列** 页面点击右上角 **新建队列**。点击队列标题旁的铅笔图标改名，按 Enter 确认。

**启动时运行** 是下拉选项：

- **每次都运行**：每次启动软件时自动运行此队列。
- **从不**：不因软件启动而运行；仍可设置定时或手动运行。
- **每日首次启动时**：同一队列当天只因软件启动自动触发一次。

[![启动时运行的三种选项](/docs/img/codex-20261104/queue-startup.png)](/docs/img/codex-20261104/queue-startup.png)

### 2. 配置整队列的定时

要在指定时间运行整个队列，保持 **队列类型** 为 **定时队列**，把 **定时运行** 设为 **是**。

[![定时队列的启动方式和定时总开关](/docs/img/codex-20261104/queue-config.png)](/docs/img/codex-20261104/queue-config.png)

在 **定时列表** 点击 **添加定时**，选择执行周期和执行时间，并将该行 **状态** 设为 **启用**。示例时间为 `06:30`，请自行调整。

[![定时列表中的状态、执行周期和时间](/docs/img/codex-20261104/queue-timer.png)](/docs/img/codex-20261104/queue-timer.png)

::: tip 两处都要启用
队列的 **定时运行 = 是**，且定时列表中的那一行 **状态 = 启用**，该定时项才会触发。配置会即时保存，刷新页面可核对。
:::

**循环队列** 则按各任务的循环设置持续运行，使用前先确认需要的是循环执行还是整队列定时。

### 3. 添加已配置的脚本

点击 **添加任务**，从下拉框选择已经配置好的脚本。这里没有可选脚本时，先完成 [脚本配置](/docs/script-guide/)。

::: tip 三种常见玩法
- **开机就代理**：将 AUTO-MAS 设为开机启动，再把队列的 **启动时运行** 设为 **每次都运行** 或 **每日首次启动时**。
- **到点就代理**：让软件保持运行，开启 **定时运行** 并设置定时项。
- **配合 MAA 自定义基建**：在基建方案切换生效前定时启动，让 MAA 顺手换班。
:::

## 自动代理时的执行顺序

**自动代理** 模式下，任务是这样一层层展开的：

- **一个用户** = 该用户勾选的所有任务。MAA 脚本的用户分 **剿灭** 和 **日常** 两块，先剿灭后日常；脚本模式默认开日常。
- **一个脚本** = 它下面所有用户的任务，按用户在列表里的顺序往下跑。同一个脚本不能同时跑两遍——已经在跑的话，重复启动会被跳过。
- **一个队列** = 队列里所有脚本的任务，按队列里的顺序往下跑。同一个队列可以重复启动。
- **一个调度台** 同时只跑一个队列。想并行跑多个队列，就多开几个调度台。

## 人工排查

代理跑完了，但你想亲眼确认每个号到底有没有做完？用 **人工排查**：AUTO-MAS 帮你逐个登号，你负责看一眼，它负责记账。

::: info 目前只支持 MAA
其他脚本暂未适配。
:::

1. 选择 **人工排查模式**，点 **开始任务**。
2. 软件启动 MAA，依次登录各个账号。
3. **每次 PRTS 登录完成后**，你自己看一眼这个号的代理情况，把没做完的任务手动确认掉。
4. 排查结束后，结果会记到 **用户管理页的状态信息** 里。
