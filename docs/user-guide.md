# 开始使用

## 什么是 AUTO-MAS？

AUTO-MAS 是一个脚本调度工具：像 MAA 这类原本需要手动启动、手动切号的脚本，可以交给它统一管理——自动切换账号配置、按顺序启动脚本、根据日志判断任务是否成功。

> AUTO-MAS: Make ALL Scripts Auto

## 安装

### 下载并安装

1. 前往 [下载页](/download/auto-mas) 获取最新版本安装包。
2. 按照安装包类型完成安装操作：
  - 安装版：解压压缩包并双击运行 `AUTO-MAS-Setup.exe`，根据安装指引完成安装。
  - 便携版：将压缩包解压至安装位置，完成解压后可以通过运行 `AUTO-MAS.exe` 启动程序。

::: tip 文件名里的这些词是什么意思

有的下载渠道会给出好几个安装包，按文件名挑就行：

| 文件名带 | 意思 | 什么时候选 |
| --- | --- | --- |
| `setup` | 安装版，运行安装程序 | 想让安装程序帮你处理好安装位置等事项 |
| 没有 `setup` | 便携版，解压即用 | 想自己决定装在哪，或者以后整个文件夹搬走 |
:::

当前发布包分安装版与便携版，首次启动都需要联网准备运行环境。带 `beta` 的版本为公测版；只想使用正式版时，选择下载页中的最新正式版。

## 第一次启动

第一次打开 AUTO-MAS 时，Runtime 会准备后端代码、Python 和依赖，界面会显示进度，请保持联网并等待完成。安装版和便携版使用相同的初始化流程。

初始化失败时，先查看失败步骤和详细原因，再使用页面提供的 **重试**、**换个下载源重试**、**检查运行环境** 或 **重建运行环境** 等入口；可用按钮随错误而变。仍无法完成时，使用 **打包日志** 并附上错误信息反馈，见 [常见问题](/docs/FAQ)。

日常运行时，受管后端会在后台检查并准备当前版本分支的修复；标题栏提示 **后端更新已就绪，下次启动生效** 后，重启应用即可应用。软件本体的新版本仍需通过更新提示或下载安装包更新；暂停更新期间不会自动检查。

## 接下来配置什么

软件里大部分设置项都有说明，把各页面过一遍即可完成配置；遇到问题再回文档对应章节查找。

两件事记一下，出问题时用得上：

- **想备份配置**：优先使用 **设置 → 高级设置 → 导出数据备份**。导出包含明文敏感配置，请妥善保管，不要用作报错附件。手动备份前请退出软件，再拷走安装目录下的 `data`、`config` 和 `history`；直接复制的加密凭据在更换电脑或重装系统后可能需要重新填写，见 [账号密码说明](/docs/FAQ#我的账号密码安全吗)。脚本安装目录、模拟器及游戏数据需另行备份。自定义外观和独立桌宠保存在 Windows 用户数据目录，不随安装文件夹迁移，请另行保留它们的 ZIP 包。
- **要反馈错误**：使用 **设置 → 高级设置 → 导出日志压缩包**；初始化失败页也有导出入口。原始日志位于安装目录的 `debug/app.log`（后端）、`debug/frontend.log`（界面），Runtime 日志位于 `debug/runtime/`。提交前检查附件，遮去账号、凭据等隐私信息。

### 找到备份与日志导出入口

1. 在左侧导航打开 **设置**，再选择页面顶部的 **高级设置** 页签，对应图中①。
2. 在 **备份与导出** 分组中，要备份或迁移配置时，点击 **导出数据备份** 一行右侧的导出按钮，对应②。
3. 要反馈错误时，在同一分组找到 **导出日志压缩包**，点击该行右侧的导出按钮，对应③。

②和③按用途选择，不需要依次导出。数据备份含明文敏感配置，不能代替报错日志包。
