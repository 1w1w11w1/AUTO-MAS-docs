# 游戏签到工具

各游戏社区的每日签到可以交给 AUTO-MAS：凭据填一次，之后随代理任务自动完成。

目前支持 **森空岛、米游社、库街区、塔吉多** 四个社区。无需手动指定角色——AUTO-MAS 会自动读取账号绑定的游戏角色并逐个签到，结果中会列出每个角色的状态。

::: warning 使用前须知

- 签到请求由 AUTO-MAS 在本地发起，Token 仅用于访问对应社区的官方接口，不会主动上传到与签到无关的第三方服务。
- Token 属于登录凭据，请勿发送给他人，也不要把 Token 写入公开日志、截图或配置仓库。
- 自动签到存在账号风控、接口变更和签到失败等风险，请自行评估并承担使用后果。

:::

## 基本用法

::: info 界面版本与演示范围
本页按 **v5.8.0-beta.3 后续 dev（3c9448bdf）** 修订。图中使用“教程演示账号”，社区凭据全部留空；只演示账号配置，不代表已经登录或签到，也不发送通知。
:::

1. 在左侧导航打开 **游戏社区**，选择页面顶部的 **签到** 页签。在 **社区设置** 分组找到 **启用社区工具**，打开该行右侧的开关，对应①。

[![步骤1：开启社区工具](/docs/img/tutorial-context-20261105-3c9448bdf/community-enable.png)](/docs/img/tutorial-context-20261105-3c9448bdf/community-enable.png)

2. 向下找到 **账号列表**，点击分组标题右侧的 **添加账号**，对应②。已有账号可点击该账号行的 **编辑**。

[![步骤2：添加社区账号](/docs/img/tutorial-context-20261105-3c9448bdf/community-add.png)](/docs/img/tutorial-context-20261105-3c9448bdf/community-add.png)

3. 在页面中央弹出的账号编辑窗口中，填写账号名及需要使用的社区凭据，对应③。本例只填写“教程演示账号”，凭据留空；实际签到需要对应社区的有效凭据。
4. 点击编辑窗口右下角的 **保存**，对应④。

[![步骤3和4：账号配置区域与保存按钮](/docs/img/tutorial-context-20261105-3c9448bdf/community-account-edit.png)](/docs/img/tutorial-context-20261105-3c9448bdf/community-account-edit.png)

5. 编辑窗口关闭后，在原页面的 **账号列表** 中查看账号名是否正确；刷新后可再次核对。图中⑤是**查看项**，只表示演示账号名称，不代表凭据有效或签到成功。

[![步骤5：查看演示账号名称](/docs/img/tutorial-context-20261105-3c9448bdf/community-account-saved.png)](/docs/img/tutorial-context-20261105-3c9448bdf/community-account-saved.png)

6. 根据需要开启 **结果通知** 和 **启动时签到**。
7. 配置有效凭据后，点击 **全部签到** 可以立即手动执行一次签到。

社区账号独立管理，一个账号可以配置多个社区；不要把它与托管中的游戏账号混为一项。账号列表中的社区标签会显示已配置社区及最近一次结果。将鼠标悬停在标签上可以查看角色、游戏、状态和奖励等详情。

### 三种触发方式

| 什么时候签 | 一天签几次 | 通知怎么发 |
| --- | --- | --- |
| **跟着代理任务签** | 每个账号每天只试一次，签过就不再请求 | 并进任务完成通知里 |
| **软件启动时签** | 与跟随代理共用每日一次的自动尝试限制 | 有新结果时单独发一条 |
| **你自己点 全部签到** | 随时都能点，不受"今天已签过"限制 | 单独发一条 |

::: tip 点了全部签到却提示稍后重试
说明自动签到正好在跑，等它结束再点。
:::

自动签到无论成功还是失败，都会记住账号当天的尝试；重启软件不会自动重试，需点击 **全部签到** 手动重试。当天按北京时间（UTC+8）计算。

未配置凭据的社区不会出现在通知中。

## 填写凭据

自行获取社区凭据后，在签到页的账号编辑窗口中填写并保存。没有社区账号时，先添加账号。

如果希望通过登录使用社区签到，可以使用第三方社区工具 [Better-MAS-Tools（BMT）](https://github.com/Lance0174/Better-MAS-Tools)。BMT 支持米游社、森空岛扫码登录，库街区手机号短信登录，以及塔吉多一次性账号密码登录；具体操作请参考该项目的说明。BMT 独立管理社区账号和签到，不会自动将凭据填写到 AUTO-MAS 中；从 BMT 获取的 Token、Cookie 等凭据可以复制到 AUTO-MAS 账号编辑窗口中对应社区的输入框，保存后直接使用。

::: warning 第三方工具声明
BMT 由社区开发者独立维护，并非 AUTO-MAS 官方项目。使用前请自行核实项目来源、了解其功能和凭据处理方式；使用第三方工具涉及账号及凭据安全，请自行评估风险。
:::

## 森空岛

森空岛签到会自动查询鹰角网络账号下的 **明日方舟** 和 **终末地** 角色。每个角色的签到状态会分别记录。

需要扫码登录时，请使用 [BMT](https://github.com/Lance0174/Better-MAS-Tools)。

### 从网页获取 Token

1. 登录[森空岛网页端](https://www.skland.com/)。
2. 在同一浏览器会话中访问[鹰角网络通行证凭证接口](https://web-api.skland.com/account/info/hg)。
3. 在返回的 JSON 中找到 `data.content`，只复制该字段的值：

   ```json
   {
     "code": 0,
     "data": {
       "content": "<Token>"
     }
   }
   ```

4. 在账号编辑窗口的 **森空岛** 输入框中粘贴 Token 并保存。

不要复制外层 JSON、`content` 两侧的引号或其他字段。需要切换账号时，建议清理浏览器 Cookie 后重新登录；直接退出网页可能使原凭证失效。

## 米游社

米游社会自动读取账号绑定的 **原神、星穹铁道、绝区零、崩坏学园 2、崩坏 3、未定事件簿** 角色，并逐个查询签到状态。配置有效的米游社 Cookie 后，还会尝试查询云原神剩余时长，无需单独填写云原神凭据。

需要扫码登录时，请使用 [BMT](https://github.com/Lance0174/Better-MAS-Tools)。

### 手动填写 Cookie

在已登录米游社网页端的开发者工具中执行 `document.cookie`，将包含认证字段的 Cookie 字符串粘贴到输入框。不要粘贴网页 HTML、完整接口响应或无关 Cookie；缺少 `cookie_token`、`stoken` 等认证字段时，后续角色查询和签到可能失败。

## 库街区

自动读取你绑定的 **战双帕弥什** 和 **鸣潮** 角色，逐个签到。

需要手机号短信登录时，请使用 [BMT](https://github.com/Lance0174/Better-MAS-Tools)。

### 获取 Token

库街区 Token 只能从客户端的本地登录数据中获取。具体位置随客户端版本和系统环境而变化，没有通用步骤。

1. 先用库街区客户端登录你要签到的账号。
2. 从本地登录数据中找到 Token。
3. 粘贴到账号编辑窗口的 **库街区** 输入框，保存。

第 2 步可以参考开源项目 [Kuro_login](https://github.com/mxyooR/Kuro_login) 的做法。

::: warning 这是第三方项目，不是 AUTO-MAS 官方的
用之前请自己看一遍代码、确认来源可靠。向任何第三方工具提供登录凭据都有风险，需自行承担。AUTO-MAS 不会索要也不会接收该项目的账号密码。
:::

账号没绑定可签到的角色时，结果里不会出现库街区的条目。Token 失效会在结果里写明失败原因。

## 塔吉多

自动查出你号上的游戏角色并签到。

塔吉多凭据可以附带云异环凭据，用于查询云异环剩余时长；云异环不是独立的登录入口。

需要账号密码登录时，请使用 [BMT](https://github.com/Lance0174/Better-MAS-Tools)。

### 手动填写凭据

输入框支持以下两种形式：

- 只填写 `refreshToken`；
- 填写凭据 JSON，可包含 `accessToken`、`refreshToken`、`uid`、`deviceId`、`roleName` 等字段。

如果同时配置云异环，可在 JSON 中加入 `cloudToken`、`cloudUserId` 和可选的 `cloudDeviceId`。凭据刷新后 AUTO-MAS 会在签到流程中更新保存的 Token，不需要每天重新登录。

## 看懂签到结果

| 状态 | 意思 | 要做什么 |
| --- | --- | --- |
| 成功 | 这次签到完成了 | 无 |
| 已签到 | 今天早就签过了，没重复领 | 无，正常情况 |
| 失败 | 请求失败、凭据过期，或读不到角色信息 | 重新获取 Token |
| 风控 | 社区那边要求额外验证，或暂时不理你 | 过一阵再试，别连续重试 |

结果按"社区 + 游戏 + 角色名"展示。没填 Token 的社区不会占位，不会看到空的 `0/0` 条目。

## 常见问题

### Token 过期了 / 签到一直失败

先确认这个账号还能在官方客户端或网页端正常登录——如果连官方都登不上，就不是 AUTO-MAS 的问题。能登上就重新取一次 Token：

重新获取对应社区的凭据，并在账号编辑窗口中填写和保存。

### 某个游戏没出现在结果里

签到工具只处理社区接口报上来的**已绑定角色**。确认那个游戏在这个社区账号下真的绑定了，然后重新点一次 **全部签到** 试试。

::: warning 反馈时不要贴出凭据
错误信息里的账号、密码、Cookie、Token 请自行涂掉再发出来。
:::
