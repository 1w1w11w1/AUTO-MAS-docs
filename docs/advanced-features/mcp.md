# MCP 服务

接上 MCP 之后，你可以让 AI 查询配置、编辑计划与队列、启动或停止任务，以及查看运行状态和历史。可用操作以客户端实际列出的工具为准；删除、清理、发布、登录和应用更新等操作不自动开放。

MCP（Model Context Protocol）是一套让 AI 调用外部工具的通用接口。你不需要了解它怎么工作，只要把下面的地址填进你的 AI 客户端就行。

## 配置

- 保持 AUTO-MAS 运行，在左侧导航打开 **工具**，查看页面顶部的 **MCP 服务** 页签。
- 等待状态变为 **MCP 服务已就绪**，复制页面显示的 **连接地址**。
- 在支持 **Streamable HTTP** 的 MCP 客户端中添加该地址。

安装版默认地址是 `http://127.0.0.1:36163/mcp`，源码开发环境默认端口是 `36164`。端口可以随运行实例改变，请以工具页显示的地址为准。

下面是支持 `mcpServers` / `url` 配置格式的客户端示例；不同客户端的配置入口和本地 HTTP 支持情况不同，请按其说明填写：

```json
{
  "mcpServers": {
    "auto-mas": {
      "url": "http://127.0.0.1:36163/mcp"
    }
  }
}
```

## 使用

配好之后，**保持 AUTO-MAS 开着**，AI 会自动连上，之后直接用自然语言指挥它就行。

服务会在主程序就绪后加载。若仍在加载，先等待；加载失败时，可在工具页查看提示并点击 **重新加载**。需要进一步排查时，提供相关日志。

::: warning AUTO-MAS 没开的话连不上
这个地址是 AUTO-MAS 自己提供的服务，软件关了服务就没了，AI 会提示连接失败。
:::
