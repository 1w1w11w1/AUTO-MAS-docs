# 模拟器管理

登记模拟器后，在脚本配置中选择模拟器配置及设备号，AUTO-MAS 会为支持的脚本填写对应连接信息，并按任务需要启动或关闭实例。

::: info 界面版本与演示范围
本页按 **v5.8.0-beta.3 后续 dev（3c9448bdf）** 修订。采集时在隔离环境中新建通用模拟器配置，再选择 **自动识别（推荐）**，保存后刷新确认类型仍保留，并打开 **管理模拟器** 窗口；没有搜索、添加或启动真实设备，也未运行游戏。
:::

## 添加模拟器

1. 在左侧导航打开 **模拟器管理**，点击 **手动添加模拟器**，对应①。图中尚无配置，按钮位于页面中央；已有配置时，使用配置页签右侧的 **手动添加多开器**。

[![步骤1：手动添加模拟器](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-add.png)](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-add.png)

2. 在新配置页签的 **模拟器配置** 分组中，展开 **模拟器类型** 下拉框，将通用模拟器改为 **自动识别（推荐）**，对应②。等待保存后，刷新页面核对类型。

[![步骤2：选择自动识别类型](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-type-select.png)](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-type-select.png)

3. 在同一配置分组的 **模拟器路径** 一行，点击右侧的 **管理模拟器**，对应③。

[![步骤3：打开管理模拟器](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-manage.png)](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-manage.png)

4. 在弹出的 **模拟器** 窗口右上方点击 **自动搜索并添加**，对应④，再选择支持的安装。搜索结果会列出版本及不能添加的原因；魔改 AVD 使用单独的添加入口。下图只展示入口，没有执行真实安装搜索。

[![步骤4：路径管理窗口中的搜索添加入口](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-paths.png)](/docs/img/tutorial-context-20261105-3c9448bdf/emulator-paths.png)

5. 添加安装后返回设备表，确认要使用的实例，再到脚本配置中绑定对应的模拟器配置和 **设备号**。

首次使用时也可直接点击模拟器管理页的 **自动搜索模拟器**。自动搜索会读取 Windows 注册表中的安装信息，**不只搜索默认安装目录**。改过安装路径的模拟器也可能被找到；便携安装或未登记的安装可能找不到。自动识别目前支持雷电 14、MuMu 6 与魔改 AVD；已有旧版模拟器可以继续使用下方的单类型配置。

一条自动识别配置可以管理多条安装路径，将实例合并为一张设备表。**MAS 设备号与模拟器自己的实例号可能不同**，给脚本绑定时请使用设备表里的 MAS 设备号。

## 各项配置怎么填

| 配置项 | 填什么 |
| --- | --- |
| **模拟器名称** | 随便起，只在 AUTO-MAS 里显示给你自己看 |
| **模拟器类型** | 新配置可选自动识别；已有单类型配置按实际安装选择 |
| **模拟器路径** | 选**多开器**的位置，不是模拟器主程序 |
| **最大等待时间** | 等模拟器启动多久。模拟器起来之后才会启动脚本，机器慢就调大 |
| **老板键** | 静默模式下 AUTO-MAS 会自动按这个键把模拟器藏起来 |

::: tip 常见的多开器路径
- MuMu12 v4：`mumu安装目录\shell\MuMuManager.exe`
- MuMu12 v5：`mumu安装目录\nx_main\MuMuManager.exe`
- 雷电：`雷电安装目录\ldconsole.exe`
:::

::: tip 还没装模拟器的话，选 MuMu12 或雷电
这两款性能和截图效果都不错，多开器适配也最完善，AUTO-MAS 对它们的支持最好。用别的模拟器可能会遇到没人踩过的坑。
:::
