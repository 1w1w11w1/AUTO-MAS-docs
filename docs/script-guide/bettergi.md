# BetterGI 配置方法

## 先了解两件事

**BetterGI** 是原神的第三方辅助工具，能执行一条龙（每日委托、清体力、地脉花、秘境、首领讨伐等）与多种进阶功能。它是**原生 GUI 配置**模式：账号由 BetterGI 原生管理，复杂设置在 BetterGI 自己的界面里完成。

AUTO-MAS 的专项适配为每个账号单独管理其 **「一条龙」任务配置、自定义配置组、账号切换归档与通知**。运行前按该账号的独立配置加载到 BetterGI，结束后回读该账号的一条龙设置并保存为独立副本。BetterGI 不需要在 MAS 里保留一份完整配置。

## 快速开始

1. 从 [BetterGI 官方仓库](https://github.com/babalae/better-genshin-impact)下载并解压。建议放在不含中文字符的路径中，并先在 BetterGI 中完成一次基础配置。
2. 打开 **托管管理** → **新建托管**，选择 **BetterGI脚本**，设置 BetterGI 的 `RootPath` 路径。
3. 添加账号，在账号编辑页选择**配置管理方式**为「独立配置」，并根据需要配置一条龙任务。
4. 点击右上角 **配置 BetterGI**，打开 BetterGI 原生界面，在其「一条龙」页面编辑名为 **「MAS独立配置」** 的配置并保存；复杂设置也在这里完成。
5. 保存后把托管加入调度队列即可。

## 配置管理方式

每个账号可选择一条龙配置的来源：

| 配置管理方式 | 适合谁 | 实际含义 |
| --- | --- | --- |
| **独立配置** | 大多数账号 | 为该账号保存一份独立的一条龙配置，运行前加载、结束后回读保存。同一托管下不同账号可不同。 |
| **原生配置** | 想让 BetterGI 自己管理配置 | 直接使用脚本当前的配置，不加载、也不回读该账号的独立配置；由原生配置账号共享。 |

> 选择「原生配置」时，下方「任务配置」与「自定义配置组」区块会整体置灰、不可编辑，由 BetterGI 原生配置决定。

### 独立配置的落地位置（重要）

开启「独立配置」后，MAS **不会改写** 你原有的那条龙实配（如 `User/OneDragon/默认配置.json`）。它会把该账号的独立配置物化到一个 **MAS 专属槽位** `{RootPath}/User/OneDragon/MAS独立配置.json`，以 `startOneDragon MAS独立配置` 启动，结束后删除该槽位（幂等）。

因此，你在 BetterGI 里要调整的始终是名为 **「MAS独立配置」** 的一条龙，而不是你自己原有的配置（那套实配全程不被读取、也不被修改）。

## 任务配置（一条龙）

BetterGI 的一条龙配置以独立 JSON 文件保存于 `{RootPath}/User/OneDragon/{名称}.json`（`Name` 字段等于文件名）。

### 一条龙名称（必填）

对应 BetterGI「一条龙」页面中已保存的配置名称，**默认「默认配置」**。选项来自 `{RootPath}/User/OneDragon/` 下现存的配置文件（「默认配置」置顶；MAS 槽位「MAS独立配置」不会出现）。

该名称决定了这个账号的这条龙基于 BetterGI 的哪一份实配来快照和使用。**选择了它并不代表运行时读写这份文件**——独立配置模式下实际读写的是「MAS独立配置」槽位，详见上文「独立配置的落地位置」。

### 内置配置组（8 个开关）

下方 8 个**胶囊开关**控制一条龙内置配置组的**执行 / 不执行**，可多选。**勾选（开启）的任务才会执行，未勾选（关闭）的不执行**：

| # | 配置组 |
| --- | --- |
| 1 | 领取邮件 |
| 2 | 合成树脂 |
| 3 | 自动地脉花 |
| 4 | 自动秘境 |
| 5 | 自动首领讨伐 |
| 6 | 自动幽境危战 |
| 7 | 领取每日奖励 |
| 8 | 领取尘歌壶奖励 |

**语义说明**：

- 这些开关是**开关，而不是删减**：关闭某组只是把该组置为关闭，**组定义会保留**，日后可随时重新打开（可逆操作）。
- 若某组当前为「开」但在配置中缺失，会自动补建并启用。
- 本系统只管理这 8 个内置组；其余设置字段（队伍、秘境、地脉花、首领讨伐等）一律原样保留、不覆盖。

### 领取奖励队伍

填写领取奖励时使用的队伍名。**留空则不覆盖** BetterGI 现有设置。

### 通用战斗队伍

通用战斗场景使用的队伍名。留空则不覆盖 BetterGI 现有设置；填写后应用到一条龙里需要战斗的四个任务（**自动地脉花、自动秘境、自动首领讨伐、自动幽境危战**），替换 BetterGI 对应任务的默认队伍。

### 通用战斗策略

自动战斗策略下拉框。选项为 **「根据队伍自动选择」** + `{RootPath}/User/AutoFight/*.txt` 目录下已放置的战斗脚本文件名（每次实时扫描，可自行放入 `.txt` 脚本增加选项）。**留空默认为「根据队伍自动选择」**。填写后与「通用战斗队伍」一样，应用到上述四个需要战斗的任务。

## 自定义配置组

自定义配置组 = 你自行在 BetterGI 一条龙界面创建、不属于上面 8 个内置组的配置组。这是本表的数据**来源**；本表只是一个**开关**：一条龙里存在但本表未列出的组**默认执行**；已加入本表的组按行的开关执行——开启则执行、关闭则不执行。

### 总开关「启用」

控制本系统是否接管自定义组的开启 / 关闭：

- **关闭（默认）**：自定义组一律**原样保留**其启用状态与顺序，启用与否由 BetterGI 内部配置决定，本系统不干预。
- **开启**：本系统按下方表格接管自定义组的启用状态。已列入表格的组按表格状态执行；已存在于 BetterGI 配置但未列入表格的组**默认执行**；已列入且启用但配置中缺失的组会自动补建。

> 首次开启且表格为空时，会**自动从 BetterGI 现有一条龙配置加载已有的自定义组**填入表格（独立配置模式下读取「MAS独立配置」槽位）。

### 添加配置组

点击「添加配置组」，从 BetterGI 现有配置中选取要纳入控制的组，输入名称后确定即可，**添加后默认启用**（名称不能与已有组重复）。未入表的组仍保留在一条龙里，不会因本表而丢失。

### 表格管理

表格列出各自定义配置组，包含「配置组名称」与「是否启用」（可点击开关切换）。可通过复选框选中若干组，再点击「删除选中」批量移除。

## 配置 BetterGI（原生设置会话）

点击右上角「配置 BetterGI」按钮，会在 BetterGI 原生界面打开一次设置会话，页面出现遮罩提示。开启「独立配置」时，请在其「一条龙」页面选择并编辑名为 **「MAS独立配置」** 的配置（不要动你原有的实配）。完成后点击「**保存设置**」结束本次会话（默认 30 分钟无操作自动超时）。保存时会**回读 BetterGI 当前的「MAS独立配置」槽位**，并快照为该账号的独立副本。

## 账号一条龙副本

每个账号持有一份一条龙配置副本，保存在 `data/{脚本ID}/{账号ID}/OneDragon/{名称}.json`。写入时的种子优先级为：

1. 该账号的副本（存在则优先）
2. BetterGI 现有一条龙实配（按「一条龙名称」）
3. 内置模板

## 常见问题

### 开启「独立配置」后，我在 BetterGI 里该改哪个一条龙？

改 **「MAS独立配置」**。独立配置模式下 MAS 读写的都是这个槽位，编排运行时也以它启动。你原有的实配（如「默认配置」）不会被读取，也不受这里编辑影响。

### 我在 BetterGI 里自己建的「默认配置」会被覆盖成「独立配置」的样子吗？

不会。MAS 只会操作「MAS独立配置」槽位，你的同名实配全程零接触——这也是独立配置模式的设计目的。

### 关闭了某个内置组，以后还能找回吗？

能。按钮是开关语义，关闭只置为关闭、不删除组定义；重新打开即可，可用状态会恢复。

### 「原生配置」为什么不能编辑任务配置？

原生配置模式下，一条龙配置完全由 BetterGI 原生配置决定，MAS 不加载也不回写该账号的独立配置，因此相关字段整体置灰。想用 MAS 管理就切回「独立配置」。

### 自定义配置组关了，我在 BetterGI 里建的组会丢吗？

不会。总开关关闭时，自定义组原样保留其启用状态与顺序，本系统不干预；只有开启总开关后，才按表格接管其启用状态。

### 战斗策略为什么有我没建过的选项？

「根据队伍自动选择」是 BetterGI 内置默认策略，其余选项来自 `{RootPath}/User/AutoFight/` 下的 `.txt` 战斗脚本文件名，由系统实时扫描得出。
