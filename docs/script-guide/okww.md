# OK-WW 配置方法

## 先了解两件事

**OK-WW** 是鸣潮的第三方自动化工具。它属于 **ok-script 家族**，与异环使用的 **OkNte** 是两个不同的子项目；本页只介绍 OK-WW。

AUTO-MAS 的专项适配只接管高频、重复的操作：启动任务、监控日志，以及按需启动和关闭游戏。复杂的 OK-WW 设置仍然交给 OK-WW 自己的 GUI，不要求 MAS 维护一份完整配置。

## 快速开始

1. 从 [OK-WW 官方仓库](https://github.com/ok-oldking/ok-wuthering-waves)下载并解压。建议放在不含中文字符的路径中，并先在 OK-WW 中完成一次基础配置。
2. 打开 **托管管理** → **新建托管**，选择 **ok-ww脚本**。
3. 设置 **ok-ww 路径**：选择包含 `ok-ww.exe` 的目录，不要选择 exe 文件本身。
4. 回到托管列表，点击该托管的 **配置 ok-ww**，打开 OK-WW 原生 GUI 并保存一次基础配置，再添加账号。已有账号可从账号页打开配置会话。
5. 如果希望 MAS 管理游戏启停，打开 **启用游戏配置**，并选择鸣潮官方启动器的 `launcher.exe`。
6. 添加账号，选择配置来源，并决定是否开启覆写常规配置。
7. 保存后把托管加入调度队列即可。

## 三种配置来源

在账号编辑页的选择器中，配置来源分为 **共享配置**、**独立配置**、**原生**：

| 配置来源 | 适合谁 | 实际含义 |
| --- | --- | --- |
| **共享配置** | 大多数账号设置相同 | 使用托管级共享的 MAS 高频配置，一个托管下的账号共用。 |
| **独立配置** | 每个账号设置不同 | 为当前账号保存独立的 MAS 高频配置。 |
| **原生** | 想让 OK-WW 自己管理复杂设置 | 优先读取 OK-WW 原有配置；复杂设置在 OK-WW 原生 GUI 中完成。 |

简单选择方法：设置基本相同就选 **共享配置**；不同账号需要不同高频设置就选 **独立配置**；希望保留 OK-WW 原生配置、只让 MAS 做调度就选 **原生**。

> **原生不等于 MAS 永远不读写文件。** 原生的意思是“优先读取外部脚本原生配置”。只要启用了覆写常规配置，MAS 仍会在本次任务启动时临时覆盖下方高频字段。

## 覆写常规配置

账号页中的 **覆写常规配置** 控制 MAS 是否使用页面下方的高频任务面板：

- **启用**：无论配置来源是托管级、账号级还是原生，启动任务时都用本页高频任务配置覆盖本次运行的对应字段。
- **关闭**：使用所选配置来源中的完整任务设置，原生账号也会保留 OK-WW 原有的完整配置。

覆写常规配置只覆盖 MAS 页面明确提供的高频字段，不会替代 OK-WW 的完整配置。想完全按 OK-WW GUI 中的复杂设置运行时，请选择 **原生** 并关闭此选项。

## 配置何时恢复

覆写常规配置是**任务运行时的临时覆盖**，不会永久改写 OK-WW 原配置：

1. 每个账号任务开始前，MAS 先备份 OK-WW `working/configs` 中的原始配置。
2. 任务运行期间，MAS 可能写入当前账号配置或覆写常规配置。
3. 任务成功、失败、异常或被停止后，MAS 都会恢复任务开始前的原始配置。

因此，覆写常规配置不会污染下一个账号，也不会把覆写常规配置永久保存进 OK-WW。只有在 **配置 ok-ww** 会话中打开 OK-WW GUI 并主动保存的内容，才会成为脚本原有配置。

## 官方启动器要求

- OK-WW 专项适配只使用鸣潮官方资源和官方启动器。
- 游戏启动器必须是官方 `launcher.exe`；**不支持 WeGame 资源或 WeGame 启动器**。
- 不使用 MAS 管理游戏启停时，可以关闭 **启用游戏配置**；这不会改变 OK-WW 的官方资源要求。

## 目前能跑哪些任务

AUTO-MAS 只接管这两个：

- **日常任务**
- **多账号日常任务**

跑完 AUTO-MAS 会让 OK-WW 自己退出，不用你管。

OK-WW 的其他任务暂时没接，需要的话直接开 OK-WW 自己跑。

## 常见问题

### 开启覆写常规配置后，OK-WW 原配置被覆盖了吗？

不会。此选项只在当前任务期间临时覆盖，任务成功、失败、异常或停止后都会恢复原配置。

### 我应该选托管、账号还是原生？

同一托管下设置相同选 **托管级（共享配置）**；不同账号需要不同设置选 **账号级（独立配置）**；复杂设置已经在 OK-WW GUI 中维护选 **原生**。原生想使用完整原生设置时，请关闭覆写常规配置。

### 游戏路径提示无效怎么办？

请重新选择鸣潮官方启动器的 `launcher.exe`。WeGame 启动器、WeGame 目录或游戏客户端 exe 都不能作为 OK-WW 专项适配的游戏路径。

### OK-WW 和 OkNte 是同一个脚本吗？

不是。它们都属于 ok-script 家族，但分别对应鸣潮和异环，配置入口、任务和适配逻辑各自独立。
